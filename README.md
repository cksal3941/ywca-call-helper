# YWCA 전화응대 업무도우미

대전여성인력개발센터(djjob.or.kr) 안내데스크·인턴이 수강생의 전화/방문 문의에
빠르고 정확하게 대응하도록 돕는 업무 보조 웹앱.

> "전화가 왔을 때 한 화면에서 검색·안내·메모·전달까지."

## 주요 기능

- **교육과정 검색** — 실시간 부분일치, 상태 필터(모집중/개강예정/모집마감/교육중/종료), **분야별 그룹·빠른필터**
- **과정 상세** — 수강료·국비지원·담당부서·강의실·**신청/정원·여석**, 교육내용/준비물/환불(수동 보강)
- **FAQ** — 질문 버튼 → 과정 정보가 채워진 답변 자동 생성(개강일·요일·모집기간 포함)
- **월 캘린더** — 개강/모집마감/종료일 표시, 과정 상세에서도 확인 가능
- **전화응대 메모** — 처리상태(안내완료/담당자연결/담당자전달/재연락필요), 재연락 목록, 90일 자동 삭제
- **오늘의 업무** — 오늘 개강/종료/모집마감·재연락·모집중 요약
- **자동 동기화 백엔드** — 사이트에서 과정 정보를 주기적으로 크롤(수동 즉시 갱신 지원)

## 기술 스택

React + Vite + TypeScript · Express(백엔드) · localStorage(메모, 서버 전송 없음)

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173, /api는 8080로 프록시)
npm run start      # 빌드 + 백엔드 서버 (http://localhost:8080, 앱+API 통합)
npm run sync       # 교육과정 데이터 수동 동기화 (src/data/courses.ts 재생성)
```

## 배포 (Windows 상시 구동)

```bash
npm run pm2:setup    # pm2 자동시작 설치 (자세한 내용 docs/deploy-pm2.md)
```

## 데이터 관련 참고

- 교육과정은 djjob.or.kr 목록 + **각 과정 상세페이지**에서 수집. 상세페이지에서 **교육내용·교육대상·제출서류·선발전형·교육특전·추가비용**과 "추가 모집 시 연장 여부"까지 함께 가져옴(일부 과정은 해당 항목이 비어 있을 수 있음).
- 담당자 이름·내선번호는 사이트에 없어 미표시.
- 준비물·환불규정은 사이트에 없어 `src/data/supplements.ts`에서 수동 관리(자동 동기화가 덮어쓰지 않음).
